# 習慣打卡本

一個單一 HTML 檔的習慣打卡 app：每天記錄習慣、看月曆和圖表、完成習慣累積點數並兌換獎勵。

## 檔案

- `index.html`：畫面結構
- `style.css`：樣式（主題色、淺色／深色模式都在 `:root` 的變數裡）
- `app.js`：程式邏輯（資料存取、各分頁畫面、事件處理）

## 資料存在哪裡

- **在 Claude 上打開**：資料存在 Claude 提供的雲端空間，只有自己看得到，手機和電腦會同步。
- **直接在瀏覽器打開這個檔案**：連不到 Claude 的雲端，資料只會存在那個瀏覽器的 localStorage，不會同步。

兩邊的資料不互通。要搬資料，請用「設定 → 備份與還原」的下載備份檔和從備份檔還原。

## 功能

- 習慣類型：打勾、選項、比例（幾分之幾或百分比）、數字（內建計算機）、時間、文字、多筆清單（可加標籤和數字欄位）
- 頻率：每天、每週指定幾天、每週幾次
- 月曆：每月目標、每天完成比例、各習慣完成率、單一習慣的數值圖表
- 點數與獎勵：點數只加不扣，獎勵可編輯、拖拉排序、依點數排序
- 設定：主題色（含自訂檢色器與儲存的顏色）、淺色／深色模式、備份與還原
